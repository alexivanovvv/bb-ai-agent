## 1.0.0

Initial release.

- Ribbon icon and **Open bb** command open [bb](https://github.com/get-bb/bb) in a tab or sidebar, via its local web interface.
- Auto-launches bb.app in the background if its local server isn't responding.
- Optional sync of provider/model/permission mode defaults into bb for the current vault's project.
- Zoom control for the embedded view.
